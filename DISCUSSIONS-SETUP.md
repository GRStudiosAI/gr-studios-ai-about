# Enable GitHub Discussions

Run `gh repo edit GRStudiosAI/gr-studios-ai-about --enable-discussions` with an authorized account. Enable Issues if needed. In the repository Discussions tab, manage categories and create the following categories with matching slugs. Templates do not create categories. Rename template files if GitHub assigns different slugs. Announcements and polls use native GitHub formats.

- Official Announcements — Announcement
- General Discussion — Open discussion
- Questions and Answers — Q&A
- Suggestions and Ideas — Open discussion
- Technical Support — Q&A
- Website Feedback — Open discussion
- Application Development — Open discussion
- Software Development — Open discussion
- Discord Bot Development — Open discussion
- Business and Services — Q&A
- Music and Entertainment — Open discussion
- Community Polls — Poll

Enable private vulnerability reporting in repository security settings if available. Verify all forms after deployment. Do not collect private inquiries in public channels.
