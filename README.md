# GR Studios AI LLC — Corporate Identity

Static HTML/CSS/JavaScript. No installation or build required.

## Deploy
1. Create a public repository named `gr-studios-ai-about` under `GRStudiosAI`.
2. Upload the contents of this archive to the repository root, including `.nojekyll`.
3. In Settings → Pages choose Deploy from a branch, `main`, `/ (root)`, and Save.
4. Visit https://grstudiosai.github.io/gr-studios-ai-about/ once deployed.

## Branding and contact
Text branding is intentional. Add verified logo and favicon assets in `assets/images/` and update page markup when available. Contact details are intentionally omitted until verified. Review all corporate statements before publishing.

## Custom domain
No CNAME is included. If using a custom domain, configure DNS and GitHub Pages, then update absolute URLs in metadata, sitemap, robots.txt and 404.html.

## Validation
Local relative links and archive contents checked. Browser rendering and live deployment not tested.

## Clean URLs and layout
All HTML files remain in the root. Navigation uses extensionless GitHub Pages URLs; verify direct access and refresh after deployment. Local file:// previews may not resolve extensionless links. The shared flex layout keeps the footer at the bottom on short pages and after content on long pages. Contact uses the public GitHub organization; no unverified email or nonfunctional form is included.
